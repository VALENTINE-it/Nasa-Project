# These are the rules to folow when doing version control
## Staging and Commits
---
- You are not supposed to add or commit unless i tell you to.
- We use the convension **feat/<feature name>** or **fix/<fix name>** or **chore/<chore name>** or **refactor/<refactor name>**


### Petty but important rules
- You must not do 1 commit for the whole project 
- You must not go outside the commit convension.


### Pushing to github
- When pushing if you dont have the credentials please ask for them. Do not assume anything.
- Always ask if there are multiple contributors and provide an opportunity to fill in the credentials of the collaborators/contributors.

## Branching
- Always create branches for every feature if at all they are not already existent and it is a new project that has not been . If they exist just use the existing one. 
- Do not Work on the main branch
- Always work on the feature branch and if merging is required to merge merge to dev branch or the development branch

## PR
- If a PR is required create the PR and wait for review depending on the projects Contributing.md

## Credentials
 - Do not push any secret credentials to remote
